# Security policy

Evrima Companion is pre-release software. Security-sensitive reports should not be disclosed in a public GitHub issue before they can be reviewed.

Use the in-app **Report Bug** page where possible, choose **Other**, and start the description with `SECURITY REPORT`. Diagnostics are optional and off by default; include them only when needed and preview the payload first.

The project intentionally does not read The Isle process memory, inject into the game, bypass/tamper with Easy Anti-Cheat, extract credentials, or bypass official-server administration/RCON controls.

This repository is the official public documentation/download location. Do not trust modified or re-hosted Companion binaries.
